#### 🕸️ MemLedger · [**demo video ↗**](https://www.youtube.com/watch?v=xmPvyoq3y0s)
*GraphHacks 2026 (WeMakeDevs × FalkorDB), Track 02: Agent Memory & Coordination*

Shared memory for agent teams where **every belief has a writer, a source, a validity window and a provenance path**. When a source turns out to be compromised, **one Cypher traversal retracts everything it said, and everything concluded from it, across all agents**.
- **Supersede, don't overwrite:** old beliefs are closed and linked, so you can time-travel to what the team believed at 13:55
- **Quarantine:** untrusted or hedged claims are stored but never handed to agents; contradictions show up as disputes
- **Grounded extraction:** the LLM proposes claims, and code keeps only those that quote their evidence verbatim
- **Tenant isolation:** one FalkorDB graph per customer, plus an MCP server so any MCP client reads the same memory
- Scored **15/16** on a 16-question scorecard against 5/16 for a last-write-wins shared log

`Python` `FastAPI` `FalkorDB` `Cypher` `Gemini` `MCP` `Docker`

#### 🌫️ [HazeBusters](https://github.com/rudrakshSoni-dev/hazebusters-aws-buildathon) · [**live ↗**](https://main.dxwuap9t49si3.amplifyapp.com/)
Serverless air-quality advisor built for an AWS hackathon. It returns a CPCB-style AQI from the nearest station, falls back to a CAMS forecast, and gives **Bedrock-generated advice in English and Hindi with Polly audio**.
